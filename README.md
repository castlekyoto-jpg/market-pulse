# MARKET PULSE — GOLD・FX・日本株・低位株の朝夜シグナル

**価格を取得してから「買い」「売り」「様子見」を表示する、個人利用向けのサンプルシステムです。** 注文や売買は実行しません。初期状態は価格なし・銘柄判定なしです（架空の売買シグナルは入っていません）。

## 表示できること

- GOLD：Yahoo FinanceのCOMEX金先物 `GC=F`（**XAUUSD現物ではありません**。XMのGOLDと価格は異なります）
- FX：USD/JPY、EUR/JPY（1時間足）
- 日本株（1日足）：`watchlist.csv` に登録した銘柄
- 低位株（1日足）：上記登録銘柄のうち**分析時点の株価が500円以下**のものを自動分類
- 朝・夜の履歴を切替、検索、銘柄別・買い売り別フィルター、価格・RSI・根拠・参考ATR水準を表示

**ご注意：東証全上場銘柄を網羅するスクリーニングではありません。** `watchlist.csv` に追加した分が対象です。価格・銘柄名は外部データの提供状況に依存し、廃止銘柄やデータ不足銘柄は表示されません。

## Windowsで使う（まず動作確認する）

1. [Python](https://www.python.org/downloads/) 3.11以降をインストール。「Add Python to PATH」を有効にしてください。
2. `run_update.bat` をダブルクリック。初回は必要パッケージをインストールし、価格取得と `data.json` の生成を試みます。ネット接続が必要です。
3. `open_dashboard.bat` をダブルクリック。ブラウザーで `http://localhost:8000` が開きます。黒いコマンド画面は閉じないでください。
4. 再度価格を更新したい場合は `run_update.bat` を実行して、ブラウザーで「画面を更新」を押します。

※ ファイルの `index.html` を直接ダブルクリックで開くと、ブラウザーの安全制限で `data.json` を読めない場合があります。上記の `open_dashboard.bat` を利用してください。

※ ローカルPCで決まった時刻に更新する場合は、Windowsの**タスクスケジューラ**に `run_update.bat` または `py -3 generate_signals.py --session auto` を平日07:07・20:07に登録してください。**PCが停止・スリープ中は更新されません。**

## PCの電源が切れていても朝・夜に自動更新させる（GitHub Actions）

詳しい操作は **`GitHub_開始手順.txt`** をご覧ください。

1. GitHubでリポジトリを作り、`index.html` など本フォルダーの内容をルートにアップロードする。**`.github/workflows/update.yml` は必須**。
2. **Settings → Pages → Build and deployment → Source を「GitHub Actions」** にする。
3. **Actions → MARKET PULSE 朝夜の自動分析とWeb公開 → Run workflow** で手動実行する。
4. 成功後、Settings → PagesのURLを開く。以後平日 **7:07・20:07（日本時間）** に再取得・的中率更新・Web再公開を試みます。定時実行は遅延・スキップする場合があります。

> **Ver.3からの変更点:** Ver.3の「Deploy from a branch」では、GitHub Actionsの `GITHUB_TOKEN` による自動コミットがPagesの再構築を引き起こさず、公開画面が古いままになることがあります。本版では `actions/upload-pages-artifact` と `actions/deploy-pages` を使って直接再公開します。

**注意:** GitHub PagesのURLは公開されます。Yahoo Financeなど価格データの再掲載可否をデータ元の利用条件で確認してください。実績履歴を公開リポジトリに登録すると他の人にも閲覧可能になります。GitHub Freeでは通常、非公開リポジトリはActions利用可でもPages公開はできません。

## 条件の変更

- 更新時刻：`.github/workflows/update.yml` の `cron` 欄。`timezone: 'Asia/Tokyo'` は日本時間です。
- 低位株の価格上限：`generate_signals.py` の `LOW_PRICE_LIMIT = 500.0`。
- 監視対象銘柄：`watchlist.csv`（1列目コード、2列目日本語名）へ証券コードを追加／削除。
- テクニカル判定：`generate_signals.py` の `calculate_signal()`。
- 低流動性警戒：20日平均売買代金が1,500万円未満の「買い」を様子見に変更。
- 株価は日足、FX・GOLDは1時間足です。遅延があり、特に7時の日本株は前営業日終値です。

### 判定ルール

1. 終値がEMA20を超える：+1、下回る：-1
2. EMA20がEMA50を超える：+1、下回る：-1
3. MACDがシグナル線を超える：+1、下回る：-1
4. RSI14が55～70未満：+1、75以上または45未満：-1、それ以外：0
5. 終値が5期間前を超える：+1、下回る：-1

+3以上なら「買い」、-3以下なら「売り」、それ以外は「様子見」。流動性の低い銘柄や値動きの大きい銘柄は「買い」を抑制。**売り = 自動空売りの推奨ではありません。** 仮のATR参考水準は1.5ATR（反対方向）、2.5ATR（同方向）で、執行の推奨値ではありません。

## 困ったとき

- 銘柄が1件も表示されない：ターミナルやActionsログを確認。Yahoo!側の制限・接続失敗・市場休場・履歴不足を確認してください。取得が0件の場合、正常な前回 `data.json` は残します。
- いくつかの銘柄だけ表示されない：`data.json` の `failed` を確認。上場廃止やソース側の未対応の場合があります。
- GOLDの表示が `GC=F`：Yahoo Financeで `XAUUSD=X` が取得できないため、**最初からCOMEX金先物**を参考表示しています。
- 単独HTMLのみでは常時データ取得・定刻起動はできません。更新プログラムが必要です。

## バージョン2の追加機能：毎日の予想・的中率・低位株ランキング

### 的中率の定義

- 毎回「買い」「売り」の予想を `history.json` に保存します。朝と夜の予想は別件として記録し、同じ時間帯で再実行しても同じ日の予想は上書きしません。
- **日本株・低位株：** 予想を発表したときに使った日足より後の**次の営業日の日足終値**で方向を答え合わせします。**GOLD・FX：** 予想を発表したときに使った1時間足より後の**次の確定1時間足終値**で検証します。
- 「買い」後に価格が上昇、「売り」後に価格が下落なら「的中」。逆方向なら「外れ」。同値や分割などで比較不能なデータは対象外、次の足が未確定なら「判定待ち」です。
- `的中率 = 的中件数 / (的中件数 + 外れ件数) × 100`。7日間・30日間・90日間と、市場別30日間・日別の成績を表示します。
- **本システムを利用し始める前の実績はありません。** 最初は的中率を「—」と表示し、予想の後に次の足が確定して、次回の更新が行われると集計されます。**バックテストの勝率ではありません。** 「様子見」の判定は集計しません。
- 利益率、リスクリワード、スプレッド、手数料、税金、実際の約定値・売買執行結果は考慮しません。「的中率が高い＝利益が出る」ではありません。株価分割や市場データの修正などによって判定不能になる場合があります。
- 過去の記録は `history.json` に原則120日保存します。**履歴をなくさないよう `history.json` を消さないでください。** `data.json` には直近の答え合わせ結果を表示するための短期履歴を保存しています。

### 低位株ランキング

- `watchlist.csv` の監視リストを初期版で268銘柄に拡張し、Ver.3では上場廃止銘柄の整理により**264銘柄**にしました（固定リスト。上場銘柄・株価は継続して更新されるため、全銘柄の上場や価格帯を保証するものではありません）。
- 低位株は **取得した最新の終値が500円以下** の監視銘柄だけを抽出。低位株の候補として登録されていても、株価が500円を超えていたら「日本株」に分類します。
- 「上昇注目順」（買い判定→スコア高い順）・「下落警戒順」（売り判定→スコア低い順）・「売買代金順」の3種類を切り替えられ、各上位30銘柄を表示します。流動性の低い銘柄は買い判定を抑制します。
- ランキングは**期待リターンや儲かる確率の順位ではありません**。データ不足・上場廃止などで取得できなかった銘柄は除外されます。**東証全上場企業を毎日総当たり検索する機能ではありません。**

### 更新・表示の注意

- 平日朝7:07・夜20:07の定時更新は、WindowsのタスクスケジューラまたはGitHub Actionsの**設定と有効化が必要**です。HTMLを開くだけでは相場データ取得は開始しません。
- 日本株の朝7時の予想は、原則前営業日の終値に基づくものです。祝日、データ提供遅延、相場の休止中には新しい足がありません。休日を含む日数集計は暦日ベースです。
- 毎日の的中率や監視対象数は**実際にデータ取得できた件数**に左右されます。データ提供元の制限によって一部または全部の銘柄が取得できない場合があります。

## Ver.3（2026年11月8日）：データ取得エラー修正

- 公式発表で上場廃止が確認できた4銘柄を監視リストから除外：**6201、9613、1757、3856**。
- アイフル（**8515**）は2026年3月30日に上場廃止となったため、2026年4月1日から上場した**ムニノバホールディングス（547A）**に置換。
- Yahoo Financeで取得できない `XAUUSD=X` は要求しません。**GOLDは `GC=F`（COMEX金先物）を参考表示**します。現物GOLDとは異なり、価格と判定が一致する保証はありません。
- 毎回 `pip install` しないよう更新用バッチを変更。ライブラリ不足のときだけインストールします。
- このZIPに**data.jsonとhistory.jsonは含まれていません**。過去の予想や的中率を残すため、既存フォルダーに新しいソース・設定を上書きしてください。**既存のdata.jsonとhistory.jsonを削除しないこと。**
- 予想の的中率はあくまで次の確定足における方向一致率。現物と先物の履歴を混ぜません。
- Yahoo Finance側の一時的障害・仕様変更で別銘柄が取得できないことはあります。これは全銘柄の将来取得を保証するものではありません。
